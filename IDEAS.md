## Транскрипция — по итогам аудита (docs/asr_audit_2026-08.md)

### Тир 0 — однострочники, ничего не ломают

- [x] `word_timestamps=True` на MLX-пути. Сейчас из-за `False` молча мёртв
      `hallucination_silence_threshold: 2.0` — его блок вложен в `if word_timestamps:`
      (mlx_whisper/transcribe.py:414,432). Заодно даёт пословные тайминги всему остальному
- [x] quality_report пишет `model: None` — читает `model_size`, а в конфиге `mlx_model`
      (dnd_pipeline.py:1236). По этому отчёту сравниваются прогоны, врать он не должен
- [x] `beam_size` не доезжает до MLX: beam search в mlx-whisper не реализован вовсе
      (decoding.py: NotImplementedError) — теперь пишем warning в лог, не прокидываем
- [x] `use_vad` / `vad_min_silence_ms` теперь работают и на MLX (регионы Silero → clip_timestamps)

### Тир 1 — основной выигрыш

- [x] VAD-регионы через штатный `clip_timestamps` у `mlx_whisper.transcribe()`.
      Silero уже в venv внутри faster-whisper (`assets/silero_vad_v6.onnx`,
      `vad.get_speech_timestamps`) — новых зависимостей ноль. Таймкоды остаются исходными,
      пересчёт не нужен. Вызывать по `transcribe()` на бакет ~10 мин, чтобы `initial_prompt`
      переинжектился (сейчас он живёт первые 30 с из 16 536). Ожидаемо: минус галлюцинации,
      прогон ×4 быстрее
- [x] Cross-track gating по синхронным дорожкам P8: RMS-окна 30 мс, окно живёт, если
      дорожка лидер или в 6 dB от лидера; кэш по отпечаткам всех дорожек; блок cross_gate
      в конфиге. На 20-мин срезе deduped_from 62 → 3, подозрительных 46 → 22
- [ ] Пороги гейта считать от перцентилей конкретной дорожки, а не константами в профиле.
      Замер: медиана дорожки Гая −46.4 dBFS при пороге `balanced` −46 dB, то есть гейт
      пропускает половину файла и борется ни с чем
