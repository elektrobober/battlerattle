# PDF-хроника сессии: дизайн

Дата: 2026-08-01. Статус: утверждён (brainstorming с Кареном).
Опирается на: [2026-08-01-ai-api-analysis-design.md](2026-08-01-ai-api-analysis-design.md) (провайдер-инфраструктура).

## Цель

Автоматизировать финальный артефакт сессии — «красивый PDF» в стиле
June-отчёта (эталон: `june/Session_June_Report.pdf`). Картинки сцен
пользователь генерирует руками (Midjourney и т.п.) по промптам, которые
готовит пайплайн; сборка PDF — полностью автоматическая и локальная.

## Решения (зафиксированы с пользователем)

- Подход: фиксированный HTML/CSS-шаблон в репо + WeasyPrint (печатная
  вёрстка: номера страниц, оглавление с номерами, @page-поля).
- Структура PDF — как в June: обложка со сценой → оглавление → сводка
  (MVP-рейтинг, вклад по категориям, кости) → рекап → зацепки и квесты →
  партия с рефами → полная хроника → MVP-разбор → кости → таймлайн.
- Стиль June: тёмная обложка с золотом, кремовые страницы с двойной
  рамкой, бордовые заголовки, футер «Хроники кампании · Сессия X · стр. N».
- Генерация картинок — вручную; пайплайн выдаёт готовые промпты.
- Рефы персонажей: `report_assets/` в папке сессии по умолчанию,
  переопределяется `pdf.assets_dir` (общая папка кампании).

## Новый AI-шаг: синтез сессии

Один запрос к провайдеру через существующую инфраструктуру
(`ai_providers`, structured outputs для anthropic, normalize+валидация для
openai_compatible).

**Вход:** summaries всех чанков + топ действий/MVP-сигналов (компактная
выжимка из `manual_ai_results/*.json`, не сырой транскрипт).

**Выход** (JSON, схема `SYNTHESIS_SCHEMA`):
- `recap: str` — проза, 4–6 абзацев, «что было в прошлый раз»
- `quest_hooks: [{title, description}]` — нерешённые нити и добытые сведения
- `scenes: [{title, chunk_index, time, image_prompt}]` — 3–5 ключевых
  сцен; `image_prompt` на английском, с деталями сцены и внешностью
  участников (внешность подмешивается из `party.json` описаний)

**Артефакты:**
- `out/session_synthesis.json` — результат
- `out/image_prompts.md` — человекочитаемо: сцена → промпт, инструкция
  куда класть файлы

**Кэш:** хэш входа в `ai_state.json` (секция `synthesis`); совпал — не
пересчитываем. `--force-synthesis` — пересчитать.

## Ассеты

`<session_dir>/report_assets/` (или `pdf.assets_dir`):

- `party.json`:
  ```json
  [{"name": "Ангрон", "class_ru": "Воин, мастер большого оружия",
    "player": "Дима", "ref": "ref.4 Ангрон.jpg",
    "appearance_en": "hulking scarred warrior with a greataxe"}]
  ```
  `appearance_en` — для подстановки в image_prompt'ы.
- Сцены: файлы `scene<N>*.png|jpg`; N соответствует порядковому номеру
  сцены из синтеза; `scene1` — обложка.
- Деградация: нет сцен → PDF без картинок сцен (секции сжимаются); нет
  `party.json` → секция «Партия» из имён конфига без рефов и описаний.

## Конфиг

```json
"pdf": {
  "enabled": true,
  "assets_dir": null,
  "campaign_title": "Хроники кампании",
  "subtitle": "D&D · Forgotten Realms"
}
```

`enabled: true` по умолчанию — сборка локальная и бесплатная. Синтез
требует `ai.enabled` (иначе PDF собирается без рекапа/зацепок/сцен — из
того, что есть, с warning).

## Шаблон и рендер

- `pdf_template/report.html.j2` + `pdf_template/style.css` в репо.
- Jinja2-рендер из: synthesis JSON, структуры отчётов (те же данные, что
  кормят `reports/*.md`: MVP-очки, вклад по категориям, статистика костей,
  таймлайн, хроника по чанкам), party.json, файлы сцен.
- Оглавление с номерами страниц — CSS `target-counter`.
- WeasyPrint → `out/Session_<session_name>_Report.pdf`.
- Данные для секций извлекаются рефакторингом `build_reports`: расчётные
  функции (MVP-очки, dice-статистика, таймлайн) выделяются так, чтобы их
  использовали и markdown-отчёты, и PDF — без дублирования логики.

## CLI

- `run` — после отчётов: синтез → `image_prompts.md` → лог «сгенерируй
  сцены по image_prompts.md, положи в report_assets/, запусти build-pdf»;
  если сцены уже лежат — сразу собирает PDF.
- `build-pdf <session_dir> [--force-synthesis]` — синтез из кэша или
  заново, сборка PDF.
- `ai-analyze` — без изменений (синтез не гоняет).

## Ошибки

- Нет weasyprint → понятная ошибка: `pip install weasyprint` +
  `brew install pango`; остальной пайплайн не затронут.
- Синтез упал / битый JSON → warning, PDF собирается без AI-секций.
- Нет `manual_ai_results/` → RuntimeError с подсказкой запустить
  ai-analyze.

## Зависимости

`jinja2`, `weasyprint` в requirements.txt (+ разово `brew install pango`).

## Тесты

- Синтез: сборка входа из фикстурных chunk-результатов, разбор ответа,
  кэш-скип, `--force-synthesis`, деградация при ошибке — моки, без сети.
- Сборка данных PDF: расчёт секций из фикстур (MVP/кости/таймлайн)
  совпадает с markdown-отчётами.
- Шаблон: Jinja2-рендер в HTML, проверка наличия секций/подстановок/
  экранирования; поведение при отсутствии сцен и party.json.
- WeasyPrint-смоук: один тест, помечен `@pytest.mark.slow`, скипается
  если weasyprint не установлен.

## Вне скоупа

- Автогенерация картинок через API (отдельная фича, если захочется).
- Изменение существующих markdown-отчётов.
- Многосессионные сборники/кампейн-бук.
